# HR Employee Attrition Prediction (Machine Learning Project)

## Overview

Employee attrition is a major challenge for organizations because high turnover can increase recruitment costs, reduce productivity, and negatively affect team performance. This project uses HR analytics data and machine learning techniques to analyze employee behaviour and predict whether an employee is likely to resign.

The project focuses on transforming raw HR data into meaningful business insights while building a predictive classification model that can support workforce planning and employee retention strategies.

---

## Why this project

Organizations collect large amounts of employee data but often struggle to identify the factors contributing to employee resignations. The goal of this project was to apply data analytics and machine learning techniques to better understand employee attrition patterns and demonstrate how predictive analytics can support HR decision-making.

This project also provided practical experience in building an end-to-end machine learning workflow, including preprocessing, feature engineering, model training, and evaluation.

---

## What I did

I analyzed HR employee data to:

* Explore employee demographics, salary, department, and training patterns
* Identify trends associated with employee resignation
* Perform data cleaning and preprocessing
* Engineer new features, such as employee tenure
* Encode categorical variables for machine learning
* Handle missing values and class imbalance
* Train and evaluate a Logistic Regression classification model
* Interpret model performance using confusion matrices and classification metrics

## Key Insights

* Salary and department appear to influence employee attrition risk
* Employee tenure may play an important role in retention patterns
* Class imbalance significantly affected model performance
* Applying balanced class weighting improved the model’s ability to detect employee resignations
* Accuracy alone was not sufficient for evaluating classification performance, making recall and F1-score important metrics

---

## Recommendations

Based on the analysis, organizations could:

* Monitor employees in higher-risk departments more closely
* Review overtime and workload patterns linked to attrition
* Improve employee engagement and retention strategies
* Use predictive analytics to proactively identify employees at risk of resigning
