# HR Employee Attrition Prediction

## Overview
This project uses machine learning to predict employee resignation based on HR-related features such as salary, department, overtime ratio, training hours, and tenure.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Workflow
- Data cleaning
- Exploratory Data Analysis
- Feature Engineering
- Encoding categorical variables
- Feature scaling
- Logistic Regression
- Model Evaluation

## Key Findings
- Salary and department influenced attrition risk
- Class imbalance affected model performance
- Balanced Logistic Regression improved resignation detection

## Future Improvements
- Random Forest
- Hyperparameter tuning
- SMOTE balancing
